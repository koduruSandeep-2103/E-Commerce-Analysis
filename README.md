## 📌 Project Overview
This project presents an end-to-end **Amazon E-Commerce Analytics Dashboard** built using **Power BI**. The goal was to analyze sales performance, customer behavior, product performance, delivery efficiency, and business trends to generate actionable insights for stakeholders.
The project includes data cleaning, modeling, DAX calculations, SQL analysis, and interactive dashboard design.

## 🚀 Tech Stack
* 📊 Power BI
* 🗄️ SQL
* 📈 Microsoft Excel
* 🔄 Power Query (M Language)
* 📐 DAX (Data Analysis Expressions)

## 📂 Dataset
The project consists of two related datasets:

### Orders Table
* 17 Columns
* 113,199 Order Records

### Customers Table
* 3 Columns
* 113,000+ Customers

Relationship:
* One-to-Many (Customers → Orders using CustomerID)
